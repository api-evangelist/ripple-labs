Ripple (legally Ripple Labs Inc.) is a blockchain and crypto-enabled financial infrastructure company whose developer surface spans Ripple Payments (RippleNet Server API, On-Demand Liquidity, Payments Direct, Report Service, and Smart Liquidation), the RLUSD stablecoin "Ripple Mint" API, and Palisade Wallet-as-a-Service for institutional digital-asset custody. Its APIs let banks, fintechs, and enterprises move money cross-border, mint and redeem the RLUSD stablecoin, run treasury and reporting, and custody digital assets. Ripple also stewards the open-source XRP Ledger (documented at xrpl.org) with first-party client libraries xrpl.js and xrpl-py. Product documentation lives at docs.ripple.com; the legacy ripplelabs.com domain redirects to ripple.com.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Ripple Labs: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
